02 · Modelado matemático

Del modelo físico a la función de transferencia

Se toma el eje vertical positivo hacia arriba y se estudian pequeñas variaciones alrededor del vuelo estacionario.

02
01

Fuerzas sobre el dron

El empuje T actúa hacia arriba. El peso mg y el arrastre aerodinámico se oponen al ascenso. Para el ascenso, el arrastre es proporcional al cuadrado de la velocidad.

ΣF = m·dv/dt
m·dv/dt = T − mg − c·v²

Para representar el arrastre en ambos sentidos de movimiento puede escribirse c·v·|v|. En ascenso (v ≥ 0), coincide con c·v².

dh/dt = v
02

Vuelo estacionario (equilibrio)

En vuelo estacionario la altitud es constante y la velocidad vertical es cero.

v₀ = 0   ;   dv/dt = 0
T₀ − mg − c·v₀² = 0
T₀ = mg

Ejemplo para una masa de 1.5 kg y gravedad de 9.81 m/s²:

T₀ = 1.5(9.81) = 14.715 N
03

Linealización mediante Taylor

Se define f(T,v) = T − mg − c·v|v| y se aproxima alrededor del punto de operación (T₀, v₀).

f ≈ f₀ + (∂f/∂T)₀·ΔT + (∂f/∂v)₀·Δv

En equilibrio: f₀ = 0, (∂f/∂T)₀ = 1 y (∂f/∂v)₀ = 0 porque v₀ = 0.

m·d(Δv)/dt = ΔT
m·d²(Δh)/dt² = ΔT

El arrastre cuadrático desaparece del modelo lineal de primer orden alrededor de v₀ = 0; continúa formando parte del modelo físico no lineal.

04

Transformada de Laplace

Con condiciones iniciales nulas, se aplica Laplace a la ecuación diferencial linealizada.

m·s²·ΔH(s) = ΔT(s)
G(s) = ΔH(s)/ΔT(s) = 1/(m·s²)

Para la masa inicial de 1.5 kg:

G(s) = 1/(1.5·s²)

El término 1.5·s² completo está en el denominador. La masa m modifica la dinámica de la planta.

03

Diagrama de bloques en lazo cerrado

Función de transferencia en lazo cerrado

Para un controlador PD, C(s) = Kp + Kd·s, y realimentación unitaria negativa:

GLC(s) = C(s)G(s) / [1 + C(s)G(s)]
GLC(s) = (Kd·s + Kp) / (m·s² + Kd·s + Kp)

Con m = 1.5, Kp = 2 y Kd = 2:

GLC(s) = (2s + 2)/(1.5s² + 2s + 2)

Representación en espacio de estados

Se define x₁ = Δh y x₂ = Δv. La entrada es ΔT y la salida es Δh.

ẋ = A·x + B·u   ;   y = C·x + D·u
A = [ 0  1 ; 0  0 ]
B = [ 0 ; 1/m ]   C = [ 1  0 ]   D = 0

Para m = 1.5, B = [0 ; 0.6667]. El modelo representa la planta linealizada antes de cerrar el lazo de control.

Código fuente · Script de simulación

Código de GNU Octave

El mismo script que aparece en las capturas originales, transcrito para facilitar su lectura y copia.

GNU Octavem = 1.5 kgKp = 2 · Kd = 2
drone_altitude_control.mOCTAVE
clc; clear; close all;
pkg load control;

% Parametros del dron
m = 1.5;
g = 9.81;

% Ganancias del controlador PD
Kp = 2;
Kd = 2;

% Funcion de transferencia en lazo abierto
G = tf(1,[m 0 0]);

% Controlador PD
C = tf([Kd Kp],1);

% Funcion de transferencia en lazo cerrado
T = feedback(C*G,1);

% Conexion invertida (realimentacion positiva)
T_inv = tf([Kd Kp],[m -Kd -Kp]);

% Mostrar funciones de transferencia
disp('Funcion en lazo abierto:');
G

disp('Funcion en lazo cerrado:');
T

disp('Funcion con conexion invertida:');
T_inv

% Calcular polos
disp('Polos en lazo abierto:');
pole(G)

disp('Polos en lazo cerrado:');
pole(T)

disp('Polos con conexion invertida:');
pole(T_inv)

% Tiempo de simulacion
t = 0:0.01:10;

% Respuestas al escalon
[y1,t1] = step(G,t);
[y2,t2] = step(T,t);
[y3,t3] = step(T_inv,t);

% Graficas comparativas
figure;

subplot(3,1,1);
plot(t1,y1);
grid on;
title('Respuesta en Lazo Abierto');
xlabel('Tiempo (s)');
ylabel('Altitud');

subplot(3,1,2);
plot(t2,y2);
grid on;
title('Respuesta en Lazo Cerrado (Estable)');
xlabel('Tiempo (s)');
ylabel('Altitud');

subplot(3,1,3);
plot(t3,y3);
grid on;
title('Respuesta con Conexion Invertida');
xlabel('Tiempo (s)');
ylabel('Altitud');

Teorema del valor final

Para una referencia escalón unitario y un lazo cerrado estable:

h(∞) = lims→0 s·H(s) = 1 m

El dron alcanza la referencia de altitud de 1 m en el modelo lineal. En lazo abierto, la respuesta a un escalón de empuje crece como t² y no posee un valor final finito.

Conclusión

El modelo matemático permite estudiar el movimiento vertical del dron considerando el empuje de las hélices, la gravedad y el arrastre aerodinámico. Al linealizar alrededor del vuelo estacionario se obtiene una planta de segundo orden, cuya función de transferencia relaciona los cambios de empuje con los cambios de altitud. La simulación muestra que el sistema en lazo abierto no mantiene una altura constante, mientras que el controlador PD con realimentación negativa permite seguir la referencia y obtener polos con parte real negativa. Cuando la realimentación se conecta de forma invertida aparece un polo positivo y la respuesta se vuelve inestable. Por tanto, la realimentación correctamente configurada es fundamental para la estabilización de altitud.

Alcance del modelo: es una aproximación lineal alrededor del vuelo estacionario. Un dron real también presenta dinámica de motores, saturación de hélices, retardo de sensores, viento y acoplamiento entre ejes; esos efectos no están incluidos en esta función de transferencia simplificada.
